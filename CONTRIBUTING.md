# Contributing

Open an issue describing the problem and a reproducible example with fictional data. For a change, create a branch, preserve the calculation contracts and both languages, and run `npm run verify`. Add a regression case when fixing behavior. Include screenshots for UI changes and describe any model/schema compatibility impact. Keep credentials and real client information out of issues and commits.

Pull requests are licensed under this repository's MIT license. Changes are reviewed before release. Version tags must match `package.json` and `app.json`.
